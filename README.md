# manabrew

Upload your [ManaBox](https://manabox.app/) collection export and brew Magic: The Gathering decks from the cards you actually own.

## Planned features

- **Collection import** — upload a ManaBox CSV; cards are matched to [Scryfall](https://scryfall.com/) data by Scryfall ID.
- **Deck ideas** — Claude suggests decks built from your collection, explains synergies, and recommends cards worth picking up.
- **Goldfish simulation** — Monte Carlo playouts of opening hands and early turns to measure mana ramp, curve, and draw consistency.

## Status

Early development. Runs locally with Docker Compose (setup coming soon).
